# Image Steganography App

A Flask web application for hiding secret text inside images using LSB steganography and decoding previously encoded images.

## Features
- Encode secret messages into images
- Decode hidden messages
- Preview encoded images
- Download encoded PNG files
- Responsive browser interface
- Ready for Vercel deployment

## Technologies
Python, Flask, Pillow, NumPy, HTML and CSS

## Run locally
```bash
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000 in your browser.

## Deploy
Push these files to GitHub and import the repository into Vercel.
